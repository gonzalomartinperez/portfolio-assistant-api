## Highest-leverage gaps

1. Golden set at 100% (P3, critical). No cassettes are committed, so replay is not run in CI and no pass rate exists. Judge labels are also empty. This needs the owner-approved recording campaign and its paid calls, so it is blocked on owner spend. Writing the harness and replay-gating wiring is already inside this repository.
2. Build once, deploy the same digest (D4, critical). The candidate identity is verified, but images are not pushed (`registry_push: false`) and no deployment consumes the digest. This is blocked on the VPS and the vps-ops repo (deployment path and registry). Dropping the 548 MB image artifact and aligning `ci.md` with reality is fixable inside this repository.
3. Stale README results block and docs (D8, Recruiter). Regenerate the block with `scripts/readme_results.py` from a fresh scorecard snapshot, then fix `repo-settings.md` and `ci.md`. Fixable inside this repository.
4. Consumer adoption of contract v1.1 (P5, P6). The portfolio snapshot is on API 1.0.0, and the two assistant APIs differ on errors. This is blocked on the portfolio repository and the pequeverso-assistant-api repository. A cross-repo contract check can be added here.
5. Security settings and alerts (D5). Four items remain: require SHA pinning, enable immutable releases, clear or dismiss the open code-scanning alerts, and merge or close PR #206. The first two are owner toggles. The CodeQL warning in `tests/evals/test_runner.py` and the alerts are fixable inside this repository.
6. Performance budgets (D6). Add a real-provider latency baseline, fill the empty `baseline`, and move at least one budget into the PR gate. Real-provider latency needs owner spend. The in-repo parts are fixable.
7. Lint, test and mutation margins (D2, D3). Reduce the 1,468 backlog findings (D, PT, S and TC first), add flaky tracking over 30 days (nightly history) and E2E depth, and raise the domain mutation ratchet above 76. Fixable inside this repository.
8. SLOs observed in production (D7). Needs deployment and vps-ops alerts. Blocked on the VPS and the vps-ops repo.
